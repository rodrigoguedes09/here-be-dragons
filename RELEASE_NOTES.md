# v1.0.0: Here be dragons

The first release. `npx here-be-dragons` turns any git repository into a fantasy map.

- **Dragons** on hotspots: complex code that keeps changing.
- **Roads** between files that change together (temporal coupling).
- **Ruins** where the main author has left (knowledge loss).
- **Forests** of code untouched for years, **mountains** of deep nesting, **walls** around tested files.
- **AI land**: how much of the realm was forged by coding agents, and where.
- An **interactive atlas** (single HTML file), a static **SVG** for your README, **JSON** for agents and CI, and a **Markdown** report.
- A **skill** for Claude Code, Codex, Cursor and other agents, plus a **GitHub Action** that keeps your README map fresh.
- Zero dependencies. Runs locally. Deterministic.
